# Security Policy & Vulnerability Disclosure

## Reporting a Vulnerability

Security is a foundational tenet of this platform. If you discover a vulnerability or security flaw within this repository, we appreciate your efforts to responsibly disclose it.

### Reporting Procedure
Please **do not** report security vulnerabilities through public GitHub issues or discussions.

Instead, please send an encrypted email report to:
- **Security Contact:** `maintainer@example.invalid`
- **PGP Key ID:** Available upon request or via public keyservers.

### Information to Include
To help us triage and resolve the issue quickly, please provide:
1. Description of the vulnerability and its potential security impact.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. Any affected configuration, scripts, or container versions.
4. Proposed remediation or patch, if available.

### Response Timeline
- **Initial Acknowledgment:** Within 24 hours of receiving the report.
- **Triage & Validation:** Within 72 hours.
- **Remediation & Patch Release:** Priority fixes deployed based on CVE severity.

Thank you for helping keep our software secure.
